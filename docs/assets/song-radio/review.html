PR 359: browse song radio without interrupting playback

Baseline: upstream main a65e85c. Candidate: the PR 359 commit that adds these captures. Every capture was made on Linux (Arch, Xvfb/X11) in demo mode, with fresh, isolated configuration and state for each capture. Demo mode makes no Spotify requests.

Before, Go to song radio replaced the queue and started the station at once. Now it opens the station as its own page and leaves the current music and queue alone. A new Start song radio item keeps the old immediate playback. Neither item is offered for local or unplayable songs. The radio page shows the song's name, artist and cover while it loads, when it fails with a retry button, and when Spotify returns an empty station.

Remaining checks

  • Loading a real station while signed in: demo mode does not contact Spotify, so these captures check layout only. Unit tests cover the resolver's handling of responses.
  • Only Linux produced these captures. The radio page reuses the shared playlist header and table, so macOS and Windows are not expected to differ.

Keys: B Before, A After, Space toggles between them.
